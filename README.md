# DODGE VERTEX

휴대폰 **세로 화면**으로 즐기는 닷지 게임입니다.
위아래로 긴 화면에서 사방에서 날아오는 탄을 피하며 30개 스테이지와 보스를 돌파하세요.
설치 가능한 웹앱(PWA)이라 휴대폰에 앱처럼 설치하고 오프라인으로도 플레이할 수 있습니다.

> 가로 화면 버전은 [dogeai](https://github.com/jioyng/dogeai)에 있습니다.

## 플레이

- **온라인**: https://jioyng.github.io/DodgeVertex/
- **휴대폰에 설치**: 위 주소를 Chrome(안드로이드)이나 Safari(아이폰)로 열고 "홈 화면에 추가" 또는 "앱 설치"
  - **세로 화면 전용**입니다. 설치한 앱은 전체 화면 + 세로 고정으로 실행됩니다.
  - 화면 아무 곳이나 드래그하면 캐릭터가 손가락을 따라 움직이고, 왼쪽 아래 ⏸ 버튼으로 일시정지합니다.
- **PC에서 로컬 실행**: `start-game.bat` 더블클릭 → 브라우저에서 `http://localhost:8766` 열림

## 조작

| 동작 | 휴대폰 | PC |
|---|---|---|
| 이동 | 화면 드래그 | 방향키 / WASD / 마우스 |
| 일시정지 | ⏸ 버튼 | P 또는 Esc |

## 스테이지

지금은 **1~26단계**가 열려 있고, **스페셜 스테이지 27~30**은 매년 1월 1일에 하나씩 열립니다 (2027년 27단계 … 2030년 30단계).
열린 마지막 스테이지를 깨면 엔딩 크레딧과 함께 다음 스페셜 스테이지가 열리는 날짜를 알려 주고, 30단계를 깨면 진짜 엔딩이 나옵니다.

뒤로 갈수록 버티기 시간(18초 → 28초), 탄 생성 속도, 탄 속도, 보스 체력(4 → 34)이 고르게 올라갑니다.
스페셜 스테이지는 매우 어렵고(보스 체력 38~46, 체력 70~80%부터 분노 모드), 30단계 최종 보스 「VERTEX」는 처음부터 분노 모드인 극악 난이도입니다.
11단계부터는 새로운 탄 궤적과 배경(신스웨이브, 디지털 비, 성운, 시간의 터널)이 나옵니다.
보스는 체력이 절반 이하가 되면 **분노 모드**로 공격이 빨라지고, 다른 패턴을 동시에 함께 씁니다.

| 탄 궤적 | 움직임 |
|---|---|
| 직선 · 휘는 탄 · 물결 · 가속 · 유도 · 벽 반사 · 분열 · 지그재그 | 기본 궤적 |
| 조준 돌진 | 멈칫하며 빨간 조준선을 그린 뒤 플레이어를 향해 돌진 |
| 부메랑 | 날아왔다가 감속해서 되돌아감 |
| 포물선 | 솟구쳤다가 아래로 떨어짐 |
| 이중 나선 | 두 발이 서로 꼬이며 날아옴 |
| 소용돌이 | 보스 주위를 돌면서 퍼져 나감 |

## 아이템

보스전에서는 아이템(19종)을 먹어 보스를 공격합니다. 2단계부터는 버티기 구간에도 가끔 방어용 아이템이 나옵니다.

| 아이템 | 효과 |
|---|---|
| ★ 에너지 오브 | 보스 공격 1회 |
| ⚡ 트리플 샷 | 3연타 |
| 💣 폭탄 | 화면의 탄 모두 제거 + 2연타 |
| 🔆 레이저 | 2.4초간 보스에 연속 공격 (4회) |
| 🛸 드론 | 12초간 주위를 돌며 보스 자동 공격 + 닿는 탄을 막음 |
| 🛡 방패 | 피격 1회 방어 |
| ⏳ 시간 감속 | 5초간 탄 속도 감소 |
| ❄ 빙결 | 2.5초간 모든 탄 정지 |
| 🧲 자석 | 9초간 아이템을 끌어당김 |
| 👻 유령화 | 3초 무적 |
| 🔹 축소 | 8초간 피격 판정 절반 |
| ❤ 생명 | 생명 +1 |
| ✨ 탄막 정화 | 화면의 모든 탄이 점수 조각으로 바뀌어 빨려 들어옴 (탄 1개당 10점) |
| 🔋 에너지 풀충전 | 생명 최대(5) + 방패 |
| 🔱 이중 레이저 | 3.5초간 양옆에서 위로 빔 발사: 지나가는 탄 소멸, 보스 밑에 있으면 연속 공격 |
| 🚀 유도 미사일 | 보스를 쫓아가는 미사일 5발 |
| 🔄 반사 방벽 | 5초간 다가오는 탄을 튕겨 냄, 5개마다 보스에 반격 |
| 🌟 스타 파워 | 5초간 무적 + 닿는 탄 파괴 + 이동 속도 증가 |
| 🌀 소용돌이 | 4초간 주변 탄을 빨아들인 뒤 폭발, 많이 삼킬수록 보스 피해 증가 |

켜져 있는 아이템 효과와 남은 시간은 화면 오른쪽 아래에 표시됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `game.js` | 게임 엔진 (탄 패턴, 보스, 아이템, 배경) |
| `bossart.js` | 보스 30종의 외형 (stages.js 의 `look` 이름별 그리기) |
| `stages.js` | 30개 스테이지 설정 (맨 아래 `STAGE_CURVE`에서 난이도 곡선 조절) |
| `audio.js` | 효과음과 배경음악 (Web Audio API로 합성) |
| `manifest.webmanifest`, `sw.js`, `pwa.js`, `icons/` | PWA 설치와 오프라인 실행 |
| `server.ps1`, `start-game.bat` | Windows용 로컬 서버 |
